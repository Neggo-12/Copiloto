# Referencias visuales — inspiración, no diseños propios

Estas 8 imágenes **no son renders del diseño de Copiloto**. Son fotos y
gráficos de productos reales o conceptos de terceros que se usaron como
referencia de forma/estética durante el brainstorm. Ninguna debe usarse
como especificación de diseño industrial de Copiloto sin decirlo
explícitamente.

| Archivo | Qué es |
| --- | --- |
| `casco.jpeg`, `casco1.jpeg`, `casco3.jpeg`, `casco4.jpeg` | Renders/fotos de cascos de terceros (incluye un producto real tipo Forcite y conceptos generados por IA) usados como referencia visual |
| `infografia-copiloto-device.png` | Infografía técnica propia: arquitectura general, modos de uso, intercomunicador, hardware/BOM, diagrama de bloques y flujo de SOS — esta sí resume contenido de Copiloto, extraída de `documento 2 completo con imagenes v2.md` |
| `infografia-casco-premium.png` | Infografía de branding "Casco Inteligente Copiloto Premium" (negro/dorado): vistas del casco, cámaras, IA, SOS, hardware, fases de desarrollo — también extraída de `documento 2 completo con imagenes v2.md` |
| `concepto-casco-negro.png` | Render de concepto de casco negro mate con luz trasera, marca "C" — inspiración de forma, no diseño final |
| `casco-xray-forcite.png` | Foto de un casco real (marca visible en la imagen) con vista de rayos-X mostrando altavoces/intercom internos — referencia de dónde va la electrónica dentro de un casco real |

Las dos infografías (`infografia-*`) sí tienen contenido específico de
Copiloto y vale la pena revisarlas antes de diseñar la interfaz de marca;
las otras cuatro son puramente inspiración de forma de casco de terceros.

# Visión integral (hardware + software combinados a propósito)

Estos dos documentos se dejaron **sin dividir** porque su propósito es
mostrar cómo el hardware y el software de Copiloto encajan como un solo
ecosistema, no describir uno u otro por separado.

- **`COPILOTO_2030_ARQUITECTURA_ESTRATEGICA_V1.docx`** — el documento más
  completo: 27 secciones que van desde la visión de producto y el cambio
  estratégico (de app de teléfono a plataforma de IA contextual), pasando
  por la arquitectura por capas (Experience/AI/Safety/Vision/Network/
  Mobility/Cloud/Edge/Devices), hasta el roadmap 2026-2030 y los riesgos
  principales. Es el documento a leer primero si alguien nuevo se une al
  proyecto.

- **`COPILOTO_MASTER_SPECIFICATION_V1.docx`** — versión más corta y
  consolidada (15 secciones) del mismo material, útil como referencia
  rápida cuando ya se conoce el proyecto.

Si necesitas solo la parte de hardware o solo la de software, usa
`../hardware/HARDWARE_SPEC.md` y `../software/SOFTWARE_ARCHITECTURE.md` —
son extracciones limpias, ya separadas, de estos mismos documentos y de
las transcripciones originales.
